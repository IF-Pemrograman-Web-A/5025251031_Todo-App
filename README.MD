## Deskripsi
Pada branch ini dilakukan migrasi kode yang sebelumnya menggunakan HTML menjadi menggunakan PHP dan dibuat menjadi modular. Ditambahkannya side bar yang memisahkan to-do-list personal dan to-do-list shared. Ditambahkan juga database yang proses modifikasinya menerapkan CRUD dengan PHP. Terdapat juga file handling berupa upload gambar yang juga menggunakan php.
